Form answer dividers: height samples

The four answers on the Contact page's form, each with a different divider height. Click through the answers in each one: the line beside the selected answer fades away so it never runs down the olive block.

A. Now: about half the height

What is live today.

B. Taller: about three quarters

Still floats, with a little air above and below.

C. Full height of an answer

Runs the full height of the answer row, edge to edge of the olive block, but stops short of the outer border.

D. All the way: touches the outer border

Runs through the box's padding and meets the border at the top and bottom, so the four answers read as separate cells.

E. All the way, same weight as the border

Like D, but 3px and full strength, matching the box's own border, so it reads as a table grid.
